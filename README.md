# Kinova Gen3-lite 接触式力控绘制系统 (EE368-Final)

本项目旨在 Kinova Gen3-lite (6 DOF) 协作机器人上实现基于关节力矩估算的末端 Z 轴主动力控绘制。系统结合了三态接触状态机、速度型外环力控与漏损积分，并针对粗糙纸箱表面的卡阻问题引入了法向力自适应衰减解阻逻辑，以保证绘制轨迹的连续性和稳定性。

---

## 📁 目录与核心脚本说明

### 1. 核心控制与测试脚本 (`tools/`)
* **`auto_contact_draw.py`**：**主运行程序**。包含全自动下探寻面、接触状态迟滞切换（`FREE_SPACE` / `SOFT_CONTACT` / `HARD_CONTACT`）、速度外环力控、Leaky 偏置更新、卡阻动态衰减目标力以及低刚度（`k_pos=0.8`）顺应性 XY 轨迹走点。
* **`force_z_monitor.py`**：**Z 轴估计力实时监控工具**。用于单独测试末端 Z 方向的受力情况。支持开机 1.5s 自动去皮，以及在终端中随时按 **[Enter 键]** 在线重新校准零偏（方便排查电机温漂）。
* **`torque_watchdog.py` / `safety_watchdog.py`**：**安全看门狗**。实时监控关节扭矩和末端受力，当扭矩超出安全范围时紧急刹停（发出 0 速度指令），防止硬件受损。
* **`align_wrist.py`**：**手腕姿态校准**。使机械臂手腕和画笔完全垂直于所绘平面。
* **`surface_calibrator.py`**：**表面校正拟合**。通过多点采样拟合绘制平面的法向量。
* **`draw_csv_trajectory.py`**：读取 CSV 轨迹并利用 matplotlib 进行二维/三维可视化。

### 2. 轨迹生成与绘图算法 (`trajectory/`)
* **`cube_circle_trajectory.py`**：生成用于测试绘制的几何轨迹（如圆形、星形、正方形等），并保存为符合机器人伺服格式的 `.csv` 航点文件。
* **`plot_trajectory_3d.py`**：三维空间下的轨迹可视化工具。

## 💻 虚拟机 (ROS 运行端) 标准操作流程

在连接好机械臂、标定好画笔后，请按以下步骤启动整个绘制系统：

### 第一步：启动 Kortex 驱动与 ROS 核心
在虚拟机终端中，启动 Kinova 驱动，确保机械臂处于正常通信状态：
```bash
roslaunch kortex_driver kortex_driver.launch
```
> ⚠️ **注意**：启动后，请将机械臂移动至**起始悬空位置**（笔尖距离纸箱表面 2~5cm，并确保笔尖悬空不受外力）。

### 第二步：启动安全看门狗 (新终端)
为了防止力控超调或碰撞造成设备损坏，请务必在后台挂载看门狗节点：
```bash
python3 tools/torque_watchdog.py
```

### 第三步：(可选) 实时受力监视与校准 (新终端)
若想单独排查传感器温偏、观察手触笔尖时的压力估计是否准确：
```bash
python3 tools/force_z_monitor.py
```
* 启动时会自动收集 40 帧关节数据去皮，终端会实时输出带进度条的估算压力。
* 测试过程中，如出现发热漂移，可在该终端按 **[Enter 键]** 随时在线归零。

### 第四步：执行自动对刀与力控绘制 (新终端)
传递轨迹 CSV 文件，启动主程序：
```bash
python3 tools/auto_contact_draw.py trajectories/star_8cm.csv
```
主程序将自动执行以下操作：
1. **自动校零去皮**：机械臂原地静止 1.5 秒完成高精度去皮。
2. **恒速下探寻面**：以 `-15mm/s` 的速度向下探测，在连续 5 帧 $F_z \ge 7.0$N 时极速刹停，并基于该接触点重新生成对齐后的平移轨迹。
3. **伺服绘制与力控接管**：自动开始绘制。
   - **接触状态机**根据受力动态在 `FREE_SPACE` (悬空寻面) ── `SOFT_CONTACT` (极柔和压紧) ── `HARD_CONTACT` (速度外环闭环力控) 之间切换。
   - **卡阻自适应解困**：当检测到纸箱凹陷卡阻（连续 8 帧 XY 位移微弱）时，将目标力衰减至最低 `2.5N`，待划出凹陷后平滑滑回标称绘制力 `6.0N`。
   - **偏置 Leaky 收敛**：悬空或提笔时，`z_offset` 采用 `0.95` 的漏损系数指数归零，防止飞车。

## ⚙️ 核心参数微调与建议

如需根据不同的笔触、画笔弹性或纸箱硬度微调表现，可在 `tools/auto_contact_draw.py` 中修改以下参数：

| 参数变量 | 默认值 | 作用说明 |
| :--- | :--- | :--- |
| `self.base_target_force` | `6.0` (N) | 标称绘制压力。若笔迹太淡可调高，纸箱凹陷严重可调低。 |
| `self.contact_threshold` | `4.0` (N) | 力控激活状态机边界判断基础阈值。 |
| `k_pos` | `0.8` | XY 位置伺服控制增益。**不可调过高**（如 1.6），降到 0.8 能让机械臂保持 XY 低刚度顺应性，顺应纸箱起伏，避免抖动。 |
| `self.kp_up` / `self.kd_up` | `0.005` / `0.001` | **过度按压区**的抬起 PD 增益。若抬笔滞后可微调大 `kp_up`。 |
| `self.kp_down` / `self.kd_down` | `0.0008` / `0.0001` | **压力不足区**的下压 PD 增益。必须保持在极小值，以保证贴面温和，防止超调敲击。 |
| `stuck_cnt >= 8` | `8` (帧) | 判定笔尖卡阻的阈值（约 0.2 秒）。若纸箱阻力极大且极易卡阻，可缩短该时间，使其更灵敏地触发解阻降压。 |
