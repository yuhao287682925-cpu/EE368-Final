# Kinova Gen3-lite 接触式力控绘制系统 (EE368-Final)

本项目旨在 Kinova Gen3-lite (6 DOF) 协作机器人上实现末端 Z 轴自适应绘制。针对 Gen3-lite 无末端独立力传感器，仅能依靠关节电流估算力矩从而产生“姿态假力”和“静摩擦干扰”的问题，系统创新性地采用了**“双重探面高精度去皮 + 纯位置平整轨迹跟随”**的控制策略。在保证轨迹连续稳定、彻底消除 Z 轴目标漂移的前提下，完美解决了在纸箱表面绘制时遭遇动摩擦卡阻及锯齿状震荡的问题。

---

## 📁 目录与核心脚本说明

### 1. 核心控制与分析脚本 (`tools/`)

* **`auto_contact_draw_flat_traj.py`**：**顶面绘制终极主程序（当前最优平整轨迹版）**。
  包含全自动寻面与原点对齐。彻底抛弃了以往容易受动摩擦假力干扰的动态力控高度补偿（`z_offset`）。
  核心亮点：
  1. **重压破冰寻面**：中速下压至 12N，强势压透结构件初始虚位形变。
  2. **绝对物理脱离**：严格向上回退 5mm 完全脱离纸箱，在绝对悬空状态下执行高精度 1.5 秒零点去皮（Zero-Calibration），滤除温漂。
  3. **轻柔探面定深**：以 3mm/s 极慢速下压至 1.2N 锁定真实纸面零点坐标，并基于此点生成绝对水平的绘图平面，整体向下压入 2.5mm 吃透画笔形变余量。
  4. **全位置强力追踪**：绘制过程锁定平面高度，开启极高刚度（`k_pos_z=8.0`，最大 80mm/s 移动速度）的纯位置跟随，拒绝一切姿态假力干扰，轨迹如刀切般平滑！

* **`analyze_error.py`**：**误差对比与三维可视化分析工具**。
  读取主程序高频记录的实际物理执行轨迹（`actual_*.csv`）与理论目标轨迹（`theo_*.csv`），计算平移均方根误差 (RMSE)，并自动通过方差推断平面，生成无失真的 2D 投影叠加图及 3D 轨迹走势对比图，清晰直观地展示闭环 P 控制带来的稳态跟随滞后。

* **`align_wrist.py`**：**位姿初始化与手腕对齐脚本**。
  用于在绘图前通过 MoveIt! 将机械臂的整体姿态调整为标准水平下探姿势，消除初始奇异点风险，确保后续下探时的 Z 轴受力能够纯粹地反映在特定关节扭矩上。

### 2. 轨迹生成算法 (`trajectory/`)

* **`cube_circle_trajectory.py`**：生成用于测试绘制的几何轨迹（如圆形、星形、正方形等），保存为 `.csv` 航点文件供主程序读取。
  * **操作方法**：直接在终端运行 `python trajectory/cube_circle_trajectory.py`，程序会自动生成包含目标坐标和法向的各种形状航点文件（如 `star_8cm.csv`）。

### 3. 历史废弃代码库 (`old/`)

* 保存了探索过程中曾经使用过的：侧边绘制脚本、初代连续泄压力控策略版、以及各类杂项工具脚本。仅供查阅，不参与主线执行。

## 💻 标准操作流程

### 第一步：启动 Kortex 驱动与 ROS 核心

在虚拟机终端中，启动 Kinova 驱动：

```bash
source ~/catkin_workspace/devel/setup.bash
roslaunch kortex_driver kortex_driver.launch arm:="gen3_lite" ip_address:="192.168.1.10"
```

> ⚠️ **注意**：启动后，请将机械臂移动至**起始悬空位置**（笔尖距离纸箱表面上方 2~5cm，并确保未受到任何物理接触）。

### 第二步：执行自动双重寻面与高速绘制 (新终端)

建议在开始前，先执行对刀脚本，保证姿态最佳：

```bash
python3 tools/align_wrist.py
```

接着，直接传递轨迹 CSV 文件，启动终极平整轨迹绘制主程序：

```bash
python3 tools/auto_contact_draw_flat_traj.py trajectory/star_8cm.csv
```

主程序将自动执行下探、退回去皮、轻探对准、以及高速高刚度绘制。绘制过程中将在后台以 40Hz 自动录制闭环日志。

### 第三步：生成误差分析图表

执行完毕后，调用分析工具对比物理与理论轨迹：

```bash
python3 tools/analyze_error.py --actual actual_executed_trajectory_position_1.csv --theo theo_mapped_trajectory_position_1.csv
```
程序将自动弹出 3D 与 2D 的对比走势图，并计算出极低量级的 RMSE 平移误差。
