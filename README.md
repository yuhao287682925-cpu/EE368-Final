# Kinova Gen3-lite 接触式力控绘制系统 (EE368-Final)

本项目旨在 Kinova Gen3-lite (6 DOF) 协作机器人上实现末端 Z 轴自适应绘制。针对 Gen3-lite 基于电流估算力矩带来的“姿态假力”问题，系统创新性地采用了**“定深位置控制保底 + 单向安全泄压阀”**的融合控制策略。在保证轨迹连续稳定、不出现误判抬笔悬空的前提下，有效解决了在粗糙纸箱表面绘制时遭遇鼓包卡阻的问题。

---

## 📁 目录与核心脚本说明

### 1. 核心控制与测试脚本 (`tools/`)

* **`auto_contact_draw.py`**：**顶面绘制主程序（当前最优版本）**。包含全自动下探真实寻面、动态轨迹原点对齐。在绘制阶段彻底摒弃了易受姿态干扰的动态 PID 力控，改用**固定 3mm 下压深度**的纯位置控制，并引入了基于物理位移检测和超高力矩阈值 (10N) 的**单向安全泄压机制**（防止纸板变形引发卡死）。
* **`side_contact_draw.py`**：**垂直侧面绘制主程序**。支持自动寻面（对齐 -Y 面），并将二维轨迹重映射至垂直立面（X-Z 平面），实现了取反重力的向上绘制防卡死逻辑。包含针对侧面动摩擦对抗的定制化力控与退缩策略。
* **`side_contact_draw_with_log.py`**：**带日志与误差分析的侧边绘制程序**。除了执行侧向绘制外，以 40Hz 高频记录底层物理轨迹。结合引入了积分项（PI控制）修正单向摩擦带来的稳态滞后。执行完毕后会自动触发误差对比程序。
* **`analyze_error.py`**：**误差对比与三维可视化分析工具**。能够提取理论目标点与实际记录点，计算平移均方根误差 (RMSE)，并自动通过方差推断平面生成 1:1 的无失真 2D 投影叠加图及 3D 轨迹走势对比图。
* **`align_wrist_side.py`**：**侧边位姿初始化脚本**。用于强行将六轴机械臂腕部旋转至完全水平指向侧壁的状态。
* **`auto_contact_draw_v1_backup.py`**：**纯动态 PID 力控版本备份**。适用于平整硬桌面等不会出现姿态“假力”干扰的理想环境。
* **`force_z_monitor.py`**：**Z 轴估计力实时监控工具**。支持开机 1.5s 自动去皮，以及在终端中随时按 **[Enter 键]** 在线重新校准零偏。
* **`torque_watchdog.py` / `safety_watchdog.py`**：**安全看门狗**。实时监控关节扭矩和末端受力，超限紧急刹停。
* **`old/`**：废弃/历史版本代码存档目录（不参与 Git 跟踪）。

### 2. 轨迹生成与绘图算法 (`trajectory/`)

* **`cube_circle_trajectory.py`**：生成用于测试绘制的几何轨迹（如圆形、星形、正方形等），保存为 `.csv` 航点文件。
* **`plot_trajectory_3d.py`**：三维空间下的轨迹可视化工具。

## 💻 虚拟机 (ROS 运行端) 标准操作流程

### 第一步：启动 Kortex 驱动与 ROS 核心

在虚拟机终端中，启动 Kinova 驱动：

```bash
source ~/catkin_workspace/devel/setup.bash
roslaunch kortex_driver kortex_driver.launch arm:="gen3_lite" ip_address:="192.168.1.10"
```

> ⚠️ **注意**：启动后，请将机械臂移动至**起始悬空位置**（笔尖距离表面 2~5cm，并确保不受外力）。

### 第二步：(可选) 实时受力监视与校准 (新终端)

若想单独排查传感器温偏、观察手触笔尖时的压力估计是否准确：

```bash
python3 tools/force_z_monitor.py
```
*(测试过程中，如出现发热漂移，可在该终端按 **[Enter 键]** 随时在线归零。)*

### 第三步：执行自动对刀与定深绘制 (新终端)

传递轨迹 CSV 文件，启动主程序：

```bash
python3 tools/auto_contact_draw.py trajectory/star_8cm.csv
```

主程序将自动执行以下操作：

1. **自动校零去皮**：机械臂原地静止 1.5 秒完成高精度去皮。
2. **恒速下探真实寻面**：以较慢速度向下探测，在连续检测到 $F_z \ge 12.0$N 且满足时间窗口时果断刹停，确认真实纸面高度。
3. **定深绘制与安全泄压**：
   - **定深保底**：强制追踪标称轨迹下方 `3mm` 的高度，依靠笔尖/纸板顺应性产生摩擦力，彻底杜绝悬空。
   - **双重卡阻检测**：当真实检测到机械臂拖不动（单周期位移极小）或受力突破 `10.0N` 的超高阈值时触发。
   - **自动抬脚跨越**：触发危机后，控制器向 Z 轴正向安全泄压（拔出笔尖最多 15mm）跨过鼓包；危机解除后平滑压回 3mm。

## ⚙️ 核心参数微调与建议

如需根据不同的笔触、画笔弹性或纸箱硬度微调表现，可在 `tools/auto_contact_draw.py` 中修改：

| 参数变量 | 默认值 | 作用说明 |
| :--- | :--- | :--- |
| `fixed_press_depth` | `0.003` (m) | 绘制时的固定下压深度。若压得太狠可改为 `0.002`，若画不上可改为 `0.004`。 |
| `k_pos` | `1.2` | XY 位置伺服控制增益。决定了跟线的紧致程度和走线最高速度。 |
| 寻面力阈值 | `12.0` (N) | 下探找平面时的接触确认阈值。 |
| 泄压避险阈值 | `10.0` (N) | 绘制时防止卡死的极高阈值。大于此值将触发 Z 轴向上泄压。 |
